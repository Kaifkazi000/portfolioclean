The goal of this portfolio is not just to show finished work, but to reflect process, consistency, and practical understanding.

Project Purpose

This portfolio is created to:

Showcase my technical skills in a structured and readable way

Track my learning journey through real implementations

Present projects with clear logic, flow, and intent

Build a professional online presence suitable for internships and roles

It is designed with simplicity, clarity, and scalability in mind.

How This Portfolio Was Created (Learning Phase)

This project was not built in one go. It evolved step by step:

Started with basic layout and component structure

Improved UI gradually with better spacing, typography, and flow

Added real data sources (GitHub, projects, experience)

Focused on clean code, not shortcuts

Refactored multiple times as understanding improved

Every section reflects what I learned at that stage, not copied templates.
